# ez-showcase — витрина портфолио

Статическая витрина работ. Чистый HTML + CSS + JS, без сборки и без npm.

Главная сетка и страницы работ используют `v2.css` и `v2.js`. Прежняя одностраничная витрина сохранена в `old/`; её GSAP и ScrollTrigger находятся в `vendor/`. Внешних запросов у страниц нет, кроме счётчика Метрики.

## Версии и экраны

- `index.html` — русская версия, `en/index.html` — английская. Правка текста или разметки идёт в обе.
- `work/` — работы, `method.html` — метод, `info.html` — информация и контакт; английские пары находятся в `en/`.
- `old/` и `old/en/` — прежние версии с рабочими разделами. Старые якоря главной перенаправляются на соответствующие страницы; адреса `/v2/…` сохранены как редиректы.
- Стилевые токены (цвета, шрифты, шаги отступов) — переменные в `:root` в начале `v2.css`. `styles.css` и `cycle.js` обслуживают архив.
- `drafts/` и `en/drafts/` — не связанные навигацией черновики с `noindex`; в `sitemap.xml` их нет.

## Где сверять текст

- Утверждённый текст — `copy-2026-09-01.md`, его машинная выжимка — `canon.mjs`.
- Решения по витрине — `decisions/DECISIONS.md` в корне репозитория.
- Почему блок устроен именно так, записано комментарием прямо над ним в `index.html` и `styles.css`. Прежде чем менять, прочитать комментарий.

## Картинки

- Кадры и видео — в `assets/`, подключаются относительными путями (из `en/` — через `../assets/`).
- Картинка ссылки 1200×630 — `assets/og-preview-v3.jpg`. Исходник — `og-source.html` (не публикуется, закрыт `.gitignore`), шрифты и цвета берёт из `styles.css`. При смене первого экрана картинку пересобирают под новым именем: мессенджеры кешируют превью по адресу.

## Проверка перед выкладкой

```bash
node automation/showcase-check/check-all.mjs
```

Четыре прогона — влезает ли в окно, нет ли пустот и наложений, соблюдён ли канон, нет ли переполнения на 176 размерах. Выкладывать только при чистом итоге.

## Выкладка

Витрина живёт на двух адресах (решение 04.09.2026), поэтому каждая правка выкладывается дважды:

- `sirking22.github.io` — пуш содержимого этой папки в одноимённый репозиторий;
- `okhotin.pages.dev` — прямая выгрузка через wrangler (Cloudflare Pages, проект okhotin).

Выкладка — публикация, делается только по слову владельца.

Служебные `.codex-context/` и `.playwright-cli/` исключены из Git и из прямой выгрузки Cloudflare через `.cfignore`. `output/` также исключён из прямой выгрузки. Публикуется корень репозитория, а не `v2/`.
