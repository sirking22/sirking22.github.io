# ez-showcase — витрина портфолио

Статическая одностраничная витрина. Чистый HTML + CSS, без сборки и без npm.

С 14.08.2026 появление блоков собрано на GSAP: библиотека и плагин ScrollTrigger лежат готовыми файлами в `vendor/` и подключаются обычными тегами со ссылкой на файл. Сборки это по-прежнему не требует, а правило «ноль внешних запросов» держится — оба файла свои, при загрузке страницы сеть не используется. Без этих файлов страница остаётся полностью читаемой: скрипт ничего не прячет, если библиотека не поднялась.

## Где править текст

Весь текст находится напрямую в `index.html` (пять секций: `#hero`, `#method`, `#chain`, `#living`, `#next`). Исходный текст-первоисточник, из которого сверстана страница, лежит в `source/vitrina-v4.md` — при правках сверяйтесь с ним, чтобы не разойтись с утверждённой формулировкой. Стилевые токены (цвета, шрифты) заданы переменными в `:root` в начале `styles.css`.

## Куда класть картинки

Кадры пока обозначены серыми плашками-плейсхолдерами (`class="frame"`) с подписью вида `[КАДР: ...]`. Когда изображения будут готовы, каждую плашку нужно заменить на `<img>` с тем же соотношением сторон (16:10 в разделе «Одна сквозная линия», 16:9 в разделе «Живая система»); саму папку для файлов изображений можно создать рядом, например `assets/`, и подключать оттуда относительными путями.
